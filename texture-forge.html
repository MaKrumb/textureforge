About Maps
Diffuse (Albedo)
The base color of your material without lighting information. Captured directly from the camera, color-balanced and gamma-corrected for linear workflow. 16-bit preserves subtle color gradients.
Roughness
Grayscale map derived from local luminance variance. Bright = rough (matte), Dark = smooth (glossy). Uses a Laplacian-based micro-detail analysis across 16 levels.
Specular
Specular reflectance map. Estimated via luminance-weighted inverse roughness, remapped to 0.04–1.0 range (PBR standard). Compatible with metalness workflows.
Normal Map
Generated via Sobel filter on the grayscale heightmap. RGB encodes XYZ surface normals. Supports OpenGL (Y+) and DirectX (Y–) conventions. Strength 1×–8×.
16-Bit Output
All maps are processed internally at full float32 precision and exported as 16-bit PNG via the browser's canvas API. The resulting files are compatible with Substance Painter, Blender, Unreal Engine, and Maya.

Note: iOS Safari exports 8-bit canvas PNGs. For true 16-bit, use the raw data export on desktop Chrome/Firefox which supports 16-bit PNG encoding.
Tips
⚠ For best results: shoot in diffuse (cloudy) light. Avoid direct sunlight — it bakes lighting into your diffuse map. Keep the camera parallel to the surface. Use 2048px for hero textures.
